# 配線表

対象：ESP32-C3 SuperMini、CDSセル、PIR人感センサー HW-740、LED、パッシブブザー。

| 部品 | 接続 |
|---|---|
| LEDのアノード（＋） | GPIO4と330Ω抵抗を直列接続 |
| LEDのカソード（−） | GND |
| CDSセルの片側 | 3.3V |
| CDSセルのもう片側 | GPIO0と10kΩ抵抗の接続点 |
| 10kΩ抵抗の反対側 | GND |
| PIR OUT | GPIO3 |
| PIR VCC | 使用するHW-740モジュールの仕様に合った電源 |
| PIR GND | GND |
| パッシブブザー＋ | GPIO5 |
| パッシブブザー− | GND |

## CDS分圧回路

```text
3.3V ── CDSセル ──┬── GPIO0
                   |
                  10kΩ
                   |
                  GND
```

## LED回路

```text
GPIO4 ── 330Ω ── LEDアノード（＋）
                    LEDカソード（−）── GND
```

## 注意

- HW-740の電源電圧・出力仕様は、実際に使用するモジュールの資料で確認してください。
- ESP32-C3のGPIOは3.3V系です。GPIOへ5Vを入力しないでください。
- GPIO番号と基板上の端子位置を混同しないよう、使用する基板の表記を確認してください。
